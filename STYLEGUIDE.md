# Style Guide

## Colors

- **Primary Blue**: `#1E3A8A` - Navigation, buttons
- **Teal**: `#0D9488` - Success, confirmation
- **Orange**: `#EA580C` - Warnings, pending status
- **Gray**: `#64748B` - Body text
- **Light Gray**: `#F1F5F9` - Backgrounds

## Fonts

**Font Family**: Inter

```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap');
```

**Sizes**:
- Heading: 32px (bold)
- Subheading: 24px (semi-bold)
- Body: 16px (regular)
